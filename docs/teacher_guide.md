# Guide d'Utilisateur : Espace Enseignant - ODSM

Ce guide est destiné aux enseignants et titulaires de classe utilisant la plateforme ODSM pour la gestion pédagogique et académique.

---

## 1. Introduction et "Mes Cours"

Dès votre connexion, vous arrivez sur votre tableau de bord personnel.
- **Liste des Cours** : Affiche tous les cours qui vous sont assignés pour l'année en cours, groupés par local (classe).
- **Indicateur d'Épreuves** : Chaque cours affiche le nombre d'épreuves déjà enregistrées pour la période active.
- **Accès Rapide** : Cliquez sur "Cahier des Côtes" pour entrer les notes d'un cours spécifique.

---

## 2. Cahier des Côtes Intelligent (Innovation: Play Safe)

Le cahier des côtes ODSM intègre des algorithmes avancés pour sécuriser la saisie des notes.

### Système "Play Safe" (Exemptions)
Si un élève est absent de manière justifiée ou exempté d'une épreuve :
- **Exemption** : Cochez la case "Exempté" lors de la saisie des notes.
- **Calcul Intelligent** : Contrairement aux systèmes classiques qui mettent 0 ou excluent simplement la note, l'algorithme "Play Safe" inclut l'élève dans les calculs de performance sans pénaliser sa moyenne, en se basant sur ses autres résultats.
- **Audit des Exemptions** : Un rapport d'audit est disponible dans la vue "Grille" pour justifier chaque exemption accordée.

### Mode Simulation (Absences)
Dans la vue **Grille**, vous pouvez activer le **Mode Simulation** :
- Ce mode permet de visualiser instantanément l'impact sur la moyenne de la classe si toutes les absences (A) étaient traitées comme des zéros (0).

### Flux de Publication
1. **Brouillon** : Vos saisies sont enregistrées mais ne sont pas encore visibles par l'administration ou les élèves.
2. **Publié** : Une fois vos notes terminées, cliquez sur "Publier" pour les rendre officielles.
3. **Modifié** : Si vous modifiez une note déjà publiée, un bandeau orange vous avertira qu'une nouvelle publication est nécessaire pour mettre les totaux à jour.

---

## 3. Espace Titulaire (Innovation: Déverrouillage)

Si vous êtes titulaire d'une classe, vous disposez d'un espace de supervision (`/teacher/titulaire`).

### Clôture et Déverrouillage
- **Suivi des Soumissions** : Visualisez en un coup d'œil quels collègues ont terminé la saisie de leurs notes (Statut "Transmis").
- **Déverrouiller (Libérer)** : Si un collègue a fait une erreur après avoir transmis son cahier, vous avez le pouvoir de le **libérer** (Unlock). Cela lui redonne l'accès en écriture tout en informant l'administration.
- **Revision Request** : L'administration peut également demander une révision globale que vous devrez coordonner avec vos enseignants.

---

## 4. Performance et Bulletins

ODSM gère trois types de structures académiques :

- **Maternelle** : Basée sur **3 trimestres (T1, T2, T3)**. Les bulletins utilisent des indicateurs de compétences spécifiques à l'éveil.
- **Primaire & Secondaire** : Basés sur des périodes (4 périodes + 2 examens semestriels).
- **Vue Panoramique** : Un tableau croisé de tous les élèves et de toutes les matières pour détecter rapidement les élèves en difficulté.

---
> [!IMPORTANT]
> **Période Verrouillée** : Une fois que vous avez cliqué sur "Clôturer la Période" pour un cours, vous ne pouvez plus faire de modifications. Contactez votre Titulaire de classe si un déverrouillage est nécessaire.
