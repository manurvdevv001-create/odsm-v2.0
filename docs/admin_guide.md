# Guide d'Utilisateur : Espace Administrateur - ODSM

Bienvenue dans le guide officiel de l'Espace Administrateur d'ODSM. Ce document est conçu pour vous aider à maîtriser les outils de gestion institutionnelle, financière et académique.

---

## 1. Tableaux de Bord et Navigation

L'Espace Administrateur offre une vue panoramique sur la santé de l'établissement.
- **Accès** : Connectez-vous avec votre matricule et sélectionnez "Dashboard" dans le menu.
- **Recherche Globale** : Utilisez la barre de recherche pour trouver rapidement un élève ou un membre du personnel.
- **Années Scolaires** : Vous pouvez basculer entre l'année active et les archives via le sélecteur situé dans l'en-tête (Header).

---

## 2. Gestion Financière (Innovation: Journal de Caisse)

Le module Finance a été repensé pour offrir une traçabilité totale en temps réel.

### Journal de Caisse (Cash Journal)
Le journal de caisse permet d'enregistrer chaque paiement entrant de manière chronologique.
- **Ajout de Paiement** : Cliquez sur "Nouveau Paiement", recherchez l'élève, spécifiez le montant et le type de frais (Minerval, Transport, etc.).
- **Mode Lecture Seule** : Si vous consultez une année archivée, le journal passe automatiquement en mode consultation pour éviter toute modification accidentelle.

### Catégorisation des Élèves
Gérez les structures de frais par catégorie d'élèves (ex: Boursiers, Enfants du personnel). 
- Cela permet d'appliquer des réductions automatiques sans modifier la structure globale des frais de la classe.

### Rapports Avancés
Générez des graphiques pour visualiser :
- Le taux de recouvrement par classe.
- Les prévisions budgétaires par rapport aux entrées réelles.

---

## 3. Gestion du Personnel (Innovation: Filtres Dynamiques)

Le module Personnel (`/staff`) intègre désormais des **Comboboxes** (filtres avec recherche intégrée).
- **Recherche Intelligente** : Au lieu de faire défiler de longues listes, commencez à taper le nom d'un enseignant pour le sélectionner instantanément.
- **Assignation des Charges** : Affectez les enseignants à des locaux et des cours. 
- **Niveaux d'enseignement** : Précisez si un membre du personnel appartient à la **Maternelle**, **Primaire** ou **Secondaire** pour adapter ses outils pédagogiques.

---

## 4. Structure Académique et Périodes

### Gestion des Locaux
Configurez les classes (ex: "7e EB A") et les cours associés. Pour les classes du secondaire, de nouveaux outils permettent d'assigner les cours directement depuis l'interface du local.

### Synchronisation des Périodes
L'administration contrôle l'ouverture et la fermeture des périodes (T1, P1, EXAM, etc.).
- **Verrouillage de Période** : Une fois qu'une période est clôturée globalement, les enseignants ne peuvent plus modifier leurs notes.
- **Coordination** : Assurez-vous que les dates correspondent aux calendriers spécifiques (Maternelle à 3 trimestres vs Secondaire à 4 périodes + 2 examens).

---

## 5. Impression des Bulletins

L'administrateur possède le privilège d'impression finale de tous les bulletins après validation des titulaires.
- **Validation** : Vérifiez que tous les cours ont été transmis par les enseignants (Statut "Transmis" dans le suivi des locaux).
- **Génération en Batch** : Imprimez toute une classe en un seul clic via le bouton "Imprimer Tout".

---
> [!TIP]
> Pour une performance optimale, l'application utilise désormais un filtrage par rôle. Les administrateurs reçoivent l'ensemble des données, tandis que les enseignants ne voient que ce qui concerne leurs classes.
